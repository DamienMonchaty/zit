## Why Zit

<CardGrid>
	<Card title="Native and light" icon="rocket">
		One executable, drawn on the GPU. It redraws only when something changes,
		and stays around 60 MB of memory with a 4,000-commit repository open.
	</Card>
	<Card title="Everything a day of Git needs" icon="list-format">
		History, staging line by line, branches, rebases, conflicts, stashes,
		worktrees — without a terminal.
	</Card>
	<Card title="GitHub built in, and optional" icon="github">
		Pull requests, reviews, checks and issues next to the graph. Switch it off
		and Zit never talks to GitHub.
	</Card>
	<Card title="Your Git, untouched" icon="seti:git">
		Zit runs your `git` for everything that writes, so hooks, credential
		helpers, the SSH agent and GPG signing all work as they already do.
	</Card>
</CardGrid>

## Fast where it counts

Measured on Linux with the released build, on an Intel Core Ultra 7 155H laptop.
Zit shows the 5,000 most recent commits of a repository.

| | A 3,866-commit project | [git/git](https://github.com/git/git) — 85,906 commits |
| --- | --- | --- |
| Read the history (open a repository) | 0.10 s | 0.99 s |
| Lay out the graph | 0.9 ms | 7 ms |
| Read the working tree's status | 5 ms | 16 ms |
| Memory, once settled | 58 MB | 79 MB |
| CPU while idle | 0.2 % | 0 % |

Zit draws a frame only when something changes, so an idle window costs nothing.
[How these numbers are measured](/project/performance/).
