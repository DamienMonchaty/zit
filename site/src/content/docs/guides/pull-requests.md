Once [GitHub is connected](/start/github/), a repository whose remote is on
GitHub has its pull requests one click away.

## The list

Open, closed or yours: each request with its author, its branch, its checks
and its reviews. `↑` `↓` (or `K` `J`) go through them, `Ctrl+F` searches them.

## A pull request

Four tabs, `1` to `4` on the keyboard:

1. **Conversation** — the description, the comments and the reviews, with
   their threads.
2. **Commits** — what it adds, commit by commit.
3. **Files** — its diff, file by file, with the review comments in place.
4. **Checks** — each check and its state. Re-run the failed ones.

## Act on it

- **Check it out**, to try it locally.
- **Comment**, **approve**, or **ask for changes** — `Ctrl+Enter` sends what is
  in the review box.
- **Reply to a conversation**, resolve it, and apply a suggested change here.
- **Ask for a review again** once the changes are in.
- **Merge** it — merge commit, squash or rebase — or turn on **auto-merge**.
- **Create** one from your branch.

Issues are there too, to browse beside the code.

Rather not? Switch GitHub off in **Settings › Integrations**, and Zit sends
nothing to GitHub at all.
