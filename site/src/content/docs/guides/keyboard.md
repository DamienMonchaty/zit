title: Keyboard shortcuts
description: Every keyboard shortcut in Zit — tabs, history, commits and panels.
---

The same list is in the app, under the keyboard button in the status bar. Any
action without a key of its own is in the command palette, `Ctrl+P`.

## Anywhere

| Keys | Does |
| --- | --- |
| `Ctrl+P` | Command palette: any action, branch or repository |
| `Ctrl+T` | New tab: open, clone or create a repository |
| `Ctrl+O` | Open a folder |
| `Ctrl+W` | Close this tab |
| `Ctrl+Tab`, `Ctrl+PgDn` | Next tab — with `Shift`, or `Ctrl+PgUp`: the previous one |
| `Ctrl+,` | Settings |
| `Ctrl+Shift+T` | A terminal in this repository's folder |
| `F5` | Refresh |

## History

| Keys | Does |
| --- | --- |
| `↑` `↓` | Previous / next commit |
| `Ctrl+F` | [Search the commits](/guides/search/) |
| `Ctrl+Z` | Undo the last commit, checkout, merge… |
| `Ctrl+Shift+Z`, `Ctrl+Y` | Redo what was just undone |
| `Esc` | Back to the graph, or cancel the bar |

## Changes

| Keys | Does |
| --- | --- |
| `Ctrl+Enter` | Commit what is staged |

## Panels

| Keys | Does |
| --- | --- |
| `Ctrl+B` | Show or hide the branches panel |
| `Ctrl+J` | Show or hide the changes panel |
| `Ctrl+Shift+F` | Focus mode: the graph alone (`Esc` leaves) |
| `Ctrl+Shift+PgUp` / `PgDn` | Move this tab left / right |
